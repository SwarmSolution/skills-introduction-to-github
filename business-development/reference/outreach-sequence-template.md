# Outreach Sequence Request Template (source of truth)

Mirrored from the user's Google Doc "Sequence [Template]"
(`1pbWyV0ETBBvTluCIiDHPvMX7V1N2pRNAn7EX-kZi_8E`) so `bd-outreach-strategist` can read it locally without
depending on the Drive connector. This is the company's real intake form for requesting a new sequence in
**Outreach** (the Outreach.io sales engagement platform) — contacts and steps get uploaded there, tracked
against a **Salesforce** code. If either tool ever gets connected, this is the shape the automation should
target.

## Section 1 — Key Details

| Field | What it captures |
|---|---|
| This Sequence is For | The account/persona/vertical the sequence targets |
| Planned Launch Date | When outreach is meant to start |
| Salesforce Code | Salesforce campaign/opportunity code this sequence rolls up to (leave as a placeholder if not yet assigned) |
| Brand | Which 3DS brand(s) the messaging centers on (DELMIA, BIOVIA, ENOVIA, etc.) |
| Experience | The 3DEXPERIENCE angle/use case in play |
| Produce Group | Product group covered |
| Products Covered, If Messaging Spans Multiple | List all brands touched if more than one |
| Sequence Goals (KPIs) | What success looks like — reply rate, meetings booked, pipeline generated, etc. |

## Section 2 — Messaging & Targeting Details

- **Key Messaging** — the core value proposition / pain point angle driving every touch.
- **Target Audience** — the persona/role/title being targeted.

## Section 5 — Sequence Structure table

Columns: **Step # | Day | Step | Manual? | Notes**

The template's own example is labeled **"High-Touch, High Customization"** and demonstrates this cadence
(this is the default pattern to follow unless the user specifies a different touch count/mix):

| Step # | Day | Step | Manual? | Notes |
|---|---|---|---|---|
| 1 | 1 | Generic Task | Manual | Review contact/account, prepare any personalization if needed |
| 2 | 1 | Email 1 | Manual | Personalized email 1 — new thread — addresses priority #1 |
| 3 | 1 | Call 1 | (blank) | Call + leave voicemail |
| 4 | 3 | LinkedIn | (blank) | View profile |
| 5 | 3 | Email 2 | Auto | Short educational email using stats |
| 6 | 8 | Call 2 | (blank) | No voicemail |
| … | … | … | … | … (template trails off here — extend the same alternating task/email/call/LinkedIn pattern for however many touches the sequence needs) |

Note the mix of channels (task, email, call, LinkedIn) and the Manual/Auto column — this is richer than a
simple 4-touch email sequence; a "call" step implies a call script, not just email/LinkedIn copy.
